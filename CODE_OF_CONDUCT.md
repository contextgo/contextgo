# Code Of Conduct

## Our Standard

ContextGo is an open source project for people building agentic software systems. We expect collaboration to be direct, technical, and respectful.

Examples of constructive behavior:

- using clear language and concrete evidence
- focusing reviews on behavior, risk, maintainability, and user impact
- respecting different experience levels and communication styles
- accepting corrections and improving the work

Examples of unacceptable behavior:

- harassment, threats, or discriminatory language
- personal attacks or sustained disruption
- publishing private information without permission
- deliberately derailing technical discussion
- using project spaces for spam or unrelated promotion

## Enforcement

Maintainers may remove comments, close issues, restrict participation, or block users when behavior harms the project or community.

If you need to report a conduct issue, use the private contact path available through the ContextGo GitHub organization or maintainers. Do not include sensitive personal information in public issues.
