# Channel Tone

Reference table for per-channel tone guidance. Skills use this to keep batch outputs from sounding identical across platforms.

These are defaults. The brand voice in `docs/brand/` always overrides.

## Paid Networks

- Meta: friendly, benefit-led, single hook
- TikTok: native, conversational, hook-first within 2 seconds
- LinkedIn: credible, business value, low gimmick
- X promoted: punchy, single message, CTA visible
- YouTube in-stream: skip-resistant hook, sound-off readability

## Social Organic

- Instagram: visual-first, lifestyle context, light copy
- TikTok: native edit style, trend awareness without forced reference
- X organic: short-form, fast cycle, lower aesthetic constraint
- LinkedIn organic: pro voice, longer narrative tolerated, proof-heavy
- YouTube shorts: vertical loop logic, hook plus payoff

## Ecommerce Surfaces

- PDP hero: claim-led, proof close to the claim
- listing card: single decisive claim
- promotion banner: deal-led with compliance-safe phrasing
- selling-point images: progressive, modular, each module owns one claim

## Email

- header: anchor on outcome, not feature
- supporting blocks: scannable hierarchy, single primary CTA
