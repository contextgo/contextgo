# Design Deliverables

## Project-level `DESIGN.md`

Should normally include:

1. visual theme and atmosphere
2. color palette and roles
3. typography rules
4. component styling rules
5. layout principles
6. depth and elevation
7. do and don't rules
8. responsive behavior
9. implementation notes for agents

## UI critique note

Should normally include:

1. what the screen is trying to do
2. highest-severity design issues
3. system-level causes
4. specific improvement moves
5. what to preserve

## Reference absorption brief

Should normally include:

1. why the reference fits
2. which signals to borrow
3. which signals to avoid
4. first-party translation rules
5. no-copy guardrails

## Frontend handoff brief

Should normally include:

1. page goal
2. chosen visual archetype
3. layout structure
4. tokens and surface rules
5. component guidance
6. responsive behavior
7. motion guidance
8. acceptance checks

## Component visual spec

Should normally include:

1. component role
2. variants and anatomy
3. visual rules
4. states
5. composition rules
6. guardrails
7. acceptance checks
