# Page Lenses

Use the correct page lens before giving design advice.

## Landing-page lens

Use for:

- marketing pages
- product homepages
- launch pages
- campaign pages
- feature storytelling pages

Questions that matter:

- What is the narrative arc?
- What must the user believe after the first screen?
- Which CTA matters most?
- Where should visual drama be concentrated?
- What sections earn space and which should be compressed?

Outputs should emphasize:

- hero strategy
- messaging hierarchy
- module sequence
- pacing
- motion moments
- trust and proof blocks

## Product-surface lens

Use for:

- dashboards
- workspaces
- settings
- tables
- forms
- operator consoles
- internal tools

Questions that matter:

- What are the highest-frequency user tasks?
- Which information needs the strongest hierarchy?
- Where does density help and where does it hurt?
- What states, actions, and feedback loops must stay visible?
- What must remain stable across screens?

Outputs should emphasize:

- shell and navigation
- content hierarchy
- component ranking
- density rules
- state design
- responsiveness

## Do not mix them blindly

A page can borrow from both lenses, but one lens must dominate.

Typical mistake:

- treating a dashboard like a marketing page
- treating a homepage like a settings panel
