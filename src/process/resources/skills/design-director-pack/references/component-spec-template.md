# Component Visual Spec Template

Use this when the design brief must go beyond page-level direction and become component-level implementation guidance.

## Required sections

### 1. Component role

- what job this component performs
- where it is used
- what it must emphasize or de-emphasize

### 2. Variants

- primary variants
- secondary variants
- size options
- density modes if relevant

### 3. Anatomy

- container
- label
- icon
- helper text
- badges, indicators, or metadata slots

### 4. Visual rules

- color and surface logic
- typography rules
- spacing and padding
- border, radius, and shadow behavior
- motion or interaction affordances

### 5. States

- default
- hover
- active
- focused
- disabled
- loading
- selected
- error or warning if relevant

### 6. Composition rules

- what can sit next to it
- what spacing it expects in lists, grids, or forms
- when it should collapse or wrap on smaller screens

### 7. Guardrails

- what must stay stable
- what must not happen

### 8. Acceptance checks

- specific conditions that make the component implementation acceptable
