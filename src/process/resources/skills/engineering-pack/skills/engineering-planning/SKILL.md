# Engineering Planning

Plan before broad edits.

Workflow:

1. Restate the goal in product terms.
2. Identify constraints: runtime boundaries, existing product model, file ownership, validation requirements.
3. Inspect the current implementation before suggesting new structure.
4. Break the work into phases with concrete files or modules.
5. Separate immediate work, deferred work, and blocked work.
6. For medium or high-risk changes, stop after the plan and wait for confirmation.

Good plans are specific, sequenced, and verifiable.
