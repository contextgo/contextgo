# Finishing A Development Branch

Completion is a workflow, not a feeling.

Workflow:

1. Verify the final implementation state before proposing next steps.
2. Identify the intended integration path: merge locally, open a PR, keep the branch, or discard it.
3. Present the options clearly and execute only the path the user chooses.
4. Re-run the relevant verification after any merge step.
5. Clean up worktrees or temporary branches only when that option was chosen explicitly.

Do not auto-merge, auto-discard, or over-claim completion while validation is still missing.
