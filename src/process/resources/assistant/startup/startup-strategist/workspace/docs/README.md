# Workspace Docs

This folder stores progressive-disclosure context for **Startup Strategist**.

These docs explain where founder-facing strategy work should land in the workspace. They are reference context for relevant tasks, not a second always-on instruction surface.

## Read This Folder As

- `docs/ideas/README.md` - idea framing, problem statements, and startup-canvas style artifacts
- `docs/market/README.md` - ICP, segment choice, and value-proposition context
- `docs/strategy/README.md` - GTM, North Star, and founder-ready strategy outputs
- `docs/specs/` - reviewed strategy specs and decision docs
- `docs/plans/` - executable plans, experiments, and verification checklists

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- schedules install through `.contextgo/schedules.json`
- this package does not currently contribute package-specific hooks
