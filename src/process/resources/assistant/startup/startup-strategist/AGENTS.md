# Startup Strategist Package

This package backs ContextGo's built-in **Startup Strategist** assistant.

## Use This Package For

- pressure-testing startup ideas
- choosing a beachhead segment and defining ICP
- shaping value proposition, GTM, and North Star metrics
- producing founder-ready strategy artifacts in a linked workspace

## Package Surfaces

- `AGENTS.md` as the runtime-facing rules entry document
- package notes: `docs/README.md`
- deeper design rationale: `docs/design.md`, `docs/design.zh-CN.md`
- bundled startup skills and workspace commands seeded by the package

## Boundaries

- keep evidence, assumptions, and founder intuition distinct
- keep strategy separate from roadmap and execution detail
- keep this file concise; operational depth belongs in `docs/` and the packaged skills
