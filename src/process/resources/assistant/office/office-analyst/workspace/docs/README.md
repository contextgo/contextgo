# Workspace Docs

This folder stores progressive-disclosure context for **Office Analyst**.

These docs explain where source-aware office analysis should land in the workspace. They are reference context for relevant tasks, not a second always-on instruction surface.

## Read This Folder As

- `docs/sources/README.md` - source inventories, file provenance, and traceability notes
- `docs/analysis/README.md` - spreadsheet analysis, query work, and reconciliation context
- `docs/reports/README.md` - reporting structure, summaries, and durable output notes
- `docs/specs/` - reviewed analysis specs and decision docs
- `docs/plans/` - executable plans and verification checklists

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- schedules install through `.contextgo/schedules.json`
- this package does not currently contribute package-specific hooks
