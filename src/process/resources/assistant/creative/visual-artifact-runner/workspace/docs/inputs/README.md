# Inputs

Use this document space when capturing the brief, report, PDF, or structured
data input that drives a visual artifact build.

Capture:

- the input shape (brief, report, PDF, structured data, theme override)
- the audience and goal of the resulting artifact
- any required constraints (tone, length, brand, embargo)
- citation pointers when the input is a long report or PDF
- any normalization decisions made before the recipe step
