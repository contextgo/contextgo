# Licensing

Remotion has commercial license constraints depending on organization, team, revenue, and use case. Treat licensing as a release blocker for commercial or scaled rendering until the user confirms their rights.

## Agent Rules

- Do not assume a project is legally clear just because it renders locally.
- Before commercial delivery, ask the user to confirm Remotion license status or point to the workspace's license note.
- Keep license keys and purchase records outside this package. Store only workspace-scoped references or requirements.
- Record any third-party assets, AI-generated media, fonts, audio, stock footage, maps, and voiceover providers in the render manifest.
- Flag model-generated media whose terms are unknown.
