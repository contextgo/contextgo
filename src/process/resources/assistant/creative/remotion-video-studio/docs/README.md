# Remotion Video Studio

Remotion Video Studio is a runtime-neutral ContextGo Agent Package for React/TypeScript-first video production with Remotion.

Use it when the desired output is a real Remotion project, componentized video, Player embed, local render, SSR render, or Lambda render plan. Use `motion-studio` for broader storyboard and motion planning when the implementation framework is not fixed. Use Infermesh / AI Media Studio for AI-generated source assets; Remotion Video Studio consumes those assets and renders the final video.
