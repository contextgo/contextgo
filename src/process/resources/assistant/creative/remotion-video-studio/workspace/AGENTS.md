# Workspace Remotion Video Rules

Use this workspace area for Remotion video projects, assets, manifests, renders, and QC.

## Required Records

- Put briefs under `docs/videos/remotion/briefs/`.
- Put project notes under `docs/videos/remotion/projects/`.
- Put generated asset ledgers under `docs/videos/remotion/assets/`.
- Put render outputs or output pointers under `docs/videos/remotion/renders/`.
- Put render manifests under `docs/videos/remotion/manifests/`.
- Put QC reports under `docs/videos/remotion/qc/`.

## Boundaries

- Generate AI media through Infermesh / AI Media Studio, then record lineage.
- Keep Remotion, AWS, Infermesh, TTS, and STT credentials out of committed workspace files.
- Run still checks before full renders.
- Run QC before publishing or handing off render outputs.
