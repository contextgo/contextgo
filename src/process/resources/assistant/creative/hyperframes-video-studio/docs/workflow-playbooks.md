# Workflow Playbooks

## Website To Video

1. Capture URL, target audience, duration, channel, and CTA.
2. Extract page hierarchy: hero, proof, features, screenshots, testimonials, pricing, CTA.
3. Create a 15-60 second scene plan.
4. Build composition with page screenshots, brand colors, scroll/pan/reveal animations, subtitles, and CTA end card.
5. Render and QC text, timing, and source fidelity.

## Article To Video

1. Distill article into hook, 3-5 beats, evidence, and CTA.
2. Decide voiceover/subtitle mode.
3. Build scenes around title cards, quotes, diagrams, chart snippets, or screenshots.
4. Render and QC subtitle readability and factual alignment.

## Data To Video

1. Identify data shape: time series, ranking, comparison, funnel, cohort, or distribution.
2. Choose chart scene recipe.
3. Bind data and animate changes.
4. QC labels, axes, color contrast, and frame-by-frame readability.

## AI Media To HyperFrames

1. Import generated assets from AI Media Studio outputs or user files.
2. Preserve each asset's source manifest where available.
3. Add text overlays, transitions, brand wrappers, subtitles, and end cards.
4. Render final video and QC both HyperFrames output and source asset lineage.
