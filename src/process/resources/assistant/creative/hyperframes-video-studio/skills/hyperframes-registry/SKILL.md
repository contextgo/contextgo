# HyperFrames Registry

Use this skill when a video should start from reusable scenes or templates instead of custom one-off composition.

## Registry Candidates

- intro and outro cards
- title/subtitle/lower-third components
- website scroll/reveal scenes
- product screenshot zoom scenes
- chart and metric cards
- timeline and changelog scenes
- quote and testimonial scenes
- AI media montage scenes
- CTA end cards

## Workflow

1. Identify the video genre and target aspect ratio.
2. Pick the smallest set of reusable scenes.
3. Adapt tokens, copy, timing, and data bindings.
4. Keep custom changes near the project unless a second consumer appears.
5. Record template/source scene names in the render manifest.

## Rules

- Do not invent an abstract template system unless reuse is real.
- Keep scene parameters explicit and readable.
- Preserve brand constraints and safe margins.
- If upstream HyperFrames registry assets are used, record source and version when available.
