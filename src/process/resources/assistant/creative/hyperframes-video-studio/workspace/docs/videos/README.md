# Videos

Use this directory for deterministic HyperFrames video work.

- `briefs/`: scripts, scene plans, source notes, and timing plans.
- `projects/`: HyperFrames project folders and composition source.
- `assets/`: images, video clips, audio, subtitles, fonts, generated media, and data files.
- `renders/`: rendered MP4/WebM outputs and preview captures.
- `manifests/`: render manifests and source lineage.
- `qc/`: QC reports and rerender notes.
