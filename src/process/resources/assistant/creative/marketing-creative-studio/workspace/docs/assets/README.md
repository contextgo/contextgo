# Assets

Use this document space when generated asset families, variant sets, and platform-spec results need to land in the workspace.

Capture:

- the asset family (paid ad creative, social asset batch, ecommerce surface, presales one-pager, event KV)
- per-variant metadata (size, aspect ratio, locale, audience, stage, version)
- the platform-precheck result for each variant
- the publish-ready signal and any open review items
- the link back to the source campaign brief in `docs/campaigns/`

Do not store final assets without trace metadata. Assets that lack trace metadata are treated as unverified and should not be marked publish-ready.
