# Campaigns

Use this document space when a campaign brief, scope, audience, channel mix, or trace history needs to land in the workspace.

Capture:

- the campaign brief (goal, audience, time window, success metric, channels)
- the brand context version and theme overlay used for the campaign
- the channel constraint map (platforms, copy length, locales, compliance markers)
- the trace metadata for every generated asset variant (brief id, theme, channel, locale, variant id, version)
- the published, scheduled, and stale state for each variant

When the source brief changes, update this folder so the `campaign-stale-marker` hook can detect prior assets that need refresh.
