# Workspace Docs

This folder stores progressive-disclosure context for **Marketing Creative Studio**.

These docs explain where brand context, campaign briefs, and asset family outputs should land in the workspace. They are reference context for relevant tasks, not a second always-on instruction surface.

## Read This Folder As

- `docs/brand/README.md` - normalized brand context, banned terms, channel preferences, and visual primitives
- `docs/campaigns/README.md` - per-campaign briefs, scope, audience, channel mix, and trace metadata
- `docs/assets/README.md` - generated asset families, variant sets, and platform-spec results

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- hook payload installs into `.contextgo/hooks/` with the selection profile under `.contextgo/hooks.json`
- schedule seeds install through `.contextgo/schedules.json`
