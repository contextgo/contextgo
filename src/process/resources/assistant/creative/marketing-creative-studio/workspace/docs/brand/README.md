# Brand Context

Use this document space to capture the normalized brand context for this workspace. The package treats this folder as the source of truth for brand identity, voice, and visual primitives.

Capture:

- the normalized brand context (identity, voice, palette, typography, motifs, do-not-do rules)
- per-locale banned-term lists and mandatory phrases
- ranked channel preferences and per-channel formatting expectations
- visual primitives library and usage rules
- the brand context version and the source materials it was distilled from

Do not invent brand identity from chat-only inputs. If the brand context is missing here, run the `marketing-context-normalizer` skill first.
