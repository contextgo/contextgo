# Marketing Creative Studio Package

This package backs ContextGo's built-in **Marketing Creative Studio** assistant.

## Use This Package For

- campaign brief to multi-channel creative output
- brand context and visual-copy pairing across paid, social, ecommerce, and presales surfaces
- batch generation of platform-aware variants (sizes, aspect ratios, locales)
- industry vertical recipes (ecommerce, SaaS, presales, event campaigns)
- pre-publish guardrails for platform specs, copy length, and brand-banned terminology

## Package Surfaces

- `AGENTS.md` as the runtime-facing rules entry document
- package notes: `docs/README.md`
- deeper rationale: `docs/design.md`, `docs/design.zh-CN.md`
- domain references: `docs/brand-inputs.md`, `docs/campaign-workflows.md`, `docs/asset-recipes.md`, `docs/review-checklist.md`, `docs/industry-templates.md`, `docs/guardrails.md`
- bundled marketing creative skills and workspace command, hook, and schedule seeds

## Boundaries

- normalize a brand context before producing creative; never improvise visual identity
- prefer this package for campaign, brand, growth, ecommerce, and presales visual work
- route product UI design, screenshot critique, and design-system distillation back to **Design Director**
- route long-form documents, decks, and slide narratives to a presentation or document package such as **Morph PPT**
- keep this file short; deeper guidance belongs in `docs/` and the packaged skills
