# Design Director Package

This package backs ContextGo's built-in **Design Director** assistant.

## Use This Package For

- choosing visual direction before UI implementation starts
- drafting project-level `DESIGN.md` style artifacts
- reviewing screenshots and absorbing Figma references
- producing page art direction, component specs, and implementation handoff

## Package Surfaces

- `AGENTS.md` as the runtime-facing rules entry document
- package notes: `docs/README.md`
- deeper design rationale: `docs/design.md`, `docs/design.zh-CN.md`
- bundled design-direction skills and workspace command seeds

## Boundaries

- choose visual direction before prescribing page details
- keep design-system, page-level art direction, and implementation handoff as distinct layers
- keep this file short; deeper guidance belongs in `docs/` and the packaged skills
