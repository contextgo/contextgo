# Workspace Docs

This folder stores progressive-disclosure context for **Design Director**.

These docs explain where visual direction, reference handling, and design handoff context should land in the workspace. They are reference context for relevant tasks, not a second always-on instruction surface.

## Read This Folder As

- `docs/direction/README.md` - visual direction, system language, and project-level design choices
- `docs/references/README.md` - screenshot critique, reference intake, and Figma absorption context
- `docs/handoff/README.md` - implementation-facing design specs and handoff notes
- `docs/specs/` - reviewed design specs and design-system decisions
- `docs/plans/` - executable implementation plans and verification checklists

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- schedules install through `.contextgo/schedules.json`
- this package does not currently contribute package-specific hooks
