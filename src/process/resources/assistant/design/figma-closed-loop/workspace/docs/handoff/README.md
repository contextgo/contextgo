# Implementation Handoff Records

Use this folder to record implementation handoff produced from Figma nodes via `figma-implementation-handoff`.

For each handoff, record:

- Figma URL, file key, and node id
- target code path
- assumptions surfaced before generation
- missing tokens or missing components called out
- whether the output is an implementation suggestion (text plan) or a scoped code-change draft (diff/patch)
- next step (apply, escalate, hold for design review)
- reviewer and timestamp

Do not record handoff that was applied without a reviewable record. Reviewability is the contract.
