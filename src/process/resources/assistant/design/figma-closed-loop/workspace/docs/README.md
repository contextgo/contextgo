# Workspace Docs

This folder stores progressive-disclosure context for **Figma Closed Loop**.

These docs hold the project-specific Figma ledger, sync notes, handoff records, and drift reports. They are reference context for closed-loop work, not a second always-on instruction surface.

## Read This Folder As

- `docs/files/README.md` — closed-loop ledger of Figma files this workspace owns or syncs
- `docs/sync/README.md` — design system rule sync and component library sync notes
- `docs/handoff/README.md` — implementation handoff records produced from Figma nodes
- `docs/drift/README.md` — periodic drift reports between code and Figma

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- schedules install through `.contextgo/schedules.json`
- this package does not currently contribute package-specific hooks
