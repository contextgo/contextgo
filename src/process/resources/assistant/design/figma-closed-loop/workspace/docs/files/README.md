# Figma File Ledger

Use this folder to keep a per-file closed-loop record for every Figma file this workspace touches.

For each Figma file, record at minimum:

- file key and Figma URL
- intent, owners, and reviewer
- write permission scope (owned, syncable, read-only, frozen)
- linked code paths (DESIGN.md, token files, component sources, screen sources)
- last successful sync, last drift audit, last handoff
- pending review items

Refusing to keep this ledger is equivalent to refusing to operate the closed loop.
