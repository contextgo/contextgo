# Sync Notes

Use this folder to record design system rule sync and component library sync runs.

For each sync run, record:

- which workflow ran (`figma-design-system-rules-sync` or `figma-library-sync`)
- the Figma file key and the originating code source (commit range, manifest, or file path)
- the staged change set, including divergent and skipped items
- the publish status (staged only, or published with explicit confirmation)
- reviewer and timestamp

Library publishes must remain a separate, explicitly confirmed event. Document the confirmation here.
