# PM Workbench Package

This package backs ContextGo's built-in **PM Workbench** assistant.

## Use This Package For

- evidence-led product discovery
- PRD drafting
- roadmap planning
- prioritization and feature investment decisions

## Package Surfaces

- runtime-facing assistant rules: `pm-workbench.md`, `pm-workbench.zh-CN.md`
- package notes: `docs/README.md`
- bundled PM workflow skills and workspace command seeds

## Boundaries

- keep discovery, PRD writing, roadmap work, and prioritization as explicit workflows
- prefer linked-workspace artifacts over ephemeral chat-only output
- keep this file concise; detailed workflow belongs in `docs/` and the bundled skills
