# Workspace Docs

This folder stores progressive-disclosure context for **PM Workbench**.

These docs explain where discovery, PRD, and roadmap context should land in the workspace. They are reference context for relevant tasks, not a second always-on instruction surface.

## Read This Folder As

- `docs/discovery/README.md` - discovery evidence, problem framing, and opportunity context
- `docs/prds/README.md` - PRD drafts, scope decisions, and requirement boundaries
- `docs/roadmap/README.md` - sequencing, prioritization, and rollout planning
- `docs/specs/` - reviewed product specs and decision docs
- `docs/plans/` - executable implementation plans and verification checklists

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- schedules install through `.contextgo/schedules.json`
- this package does not currently contribute package-specific hooks
