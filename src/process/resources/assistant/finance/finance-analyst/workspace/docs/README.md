# Workspace Docs

This folder stores progressive-disclosure context for **Finance Analyst**.

These docs explain where statement analysis, valuation work, and finance decision support should land in the workspace. They are reference context for relevant tasks, not a second always-on instruction surface.

## Read This Folder As

- `docs/analysis/README.md` - statement review, benchmark work, and variance analysis
- `docs/valuation/README.md` - valuation framing, comparable sets, and modeling assumptions
- `docs/scenarios/README.md` - scenario planning, memo drafting, and decision-ready outputs
- `docs/specs/` - reviewed finance specs and decision docs
- `docs/plans/` - executable plans and verification checklists

## Workspace State

- packaged skills install under `.contextgo/skills`
- command entry points install through `.contextgo/commands.json`
- schedules install through `.contextgo/schedules.json`
- this package does not currently contribute package-specific hooks
