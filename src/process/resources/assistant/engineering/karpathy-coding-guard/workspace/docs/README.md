# Workspace Docs Map

This workspace scaffold is tuned for coding tasks that need stronger boundary control.

Use these folders as the default artifact map:

- `docs/assumptions/`
  - unresolved ambiguity, clarified assumptions, and decision checkpoints before coding
- `docs/changes/`
  - intended file scope, non-goals, and notes on why the change boundary should stay narrow
- `docs/verification/`
  - success criteria, verification commands, and results captured after implementation
