# Engineering Workspace

This folder stores durable engineering artifacts for the **Superpowers Harness** workflow stack.

## Recommended Contents

- `docs/specs/` for approved designs, decision records, and scope boundaries
- `docs/plans/` for executable implementation plans and rollout checklists
- `docs/reviews/` for review findings, fix tracking, and verification notes
- `docs/testing.md` for project-specific testing strategy and quality gates

## Working Rule

Keep the important context here once it should survive beyond a single session.
