# Connection Format

Accepted inputs for all shell apps:

- Official Remote default:
  - `https://remote.contextgo.io/login`

- Base WebUI URL:
  - `http://192.168.1.10:3000`
  - normalized to `http://192.168.1.10:3000/login`

- QR-login URL generated by ContextGo:
  - `http://192.168.1.10:3000/qr-login?token=...`
  - loaded as-is

Rejected inputs:

- non-HTTP schemes
- empty values
- malformed URLs

Reasoning:

- The shell should attach to the real ContextGo WebUI origin so cookies, `/login`, `/api/*`, and the browser-side WebSocket bridge all continue to work without rewriting the current product architecture.
