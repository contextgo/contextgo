# Choose Your Setup

Not every user should start from the same setup.

The best first step is to pick the setup that matches your real working style.

## Desktop-only

Best when you mainly work on one machine and want to make local work succeed first.

## Desktop plus web

Best when you want to step away from the desktop but still continue tasks from a browser.

## Desktop plus mobile

Best when you want the desktop host to keep working while you check and control tasks from your phone.

## Builder setup

Best for developers and builders working with code runtimes, project docs, browser context, and automation.

## Publication setup

Best when your goal is to publish an agent into a real channel instead of keeping it private.
