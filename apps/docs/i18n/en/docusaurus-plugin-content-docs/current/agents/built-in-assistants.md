# Built-in Assistants

One advantage of ContextGo is that users do not need to assemble every capability on day one.

Built-in assistants exist so you can start from a working mode instead of from a blank system.

## When they are useful

They are a good fit when:

- you are new to the product
- you are still learning which runtime and capability mix suits your work
- you want a fast working entry point

## How they differ from runtimes

A runtime answers:

- who executes

A built-in assistant answers:

- what kind of working mode you start with
