# Uploads, Files, And Host Processing

An important boundary in the remote model is:

- files can be selected on web or mobile
- real processing still continues on the host

## Why this matters

It shapes user expectation:

- the phone is not the full execution host
- uploads become part of the host-side work system
- later work continues against the host-side copy
