# Remote Access Overview

The remote model in ContextGo can be summarized in one sentence:

> The desktop host keeps execution authority, while web and mobile remain access and control surfaces.

## Why this matters

It explains:

- why the phone does not fully replace the desktop host
- why host availability matters so much
- why remote use and local execution remain different layers
