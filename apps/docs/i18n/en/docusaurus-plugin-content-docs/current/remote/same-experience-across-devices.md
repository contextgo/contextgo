# Same Experience Across Devices

ContextGo is not trying to build three unrelated products for desktop, web, and mobile.

The better goal is:

- one core product model
- multiple access surfaces
- as much continuity as possible across devices

## Why this matters

If all three surfaces behave like different products, users must learn the system multiple times.

ContextGo is better when:

- the desktop host remains the authority
- web and mobile share the same remote mental model
