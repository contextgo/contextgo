# Multi-Agent Collaboration

Multi-agent collaboration is not simply "open more bots".

Its value comes from:

- role separation
- comparison
- staged execution
- reduced single-agent bias

## Good fit when

- the task is naturally multi-stage
- different roles should make different judgments
- planning, execution, and review should not collapse into one voice
