# Publish-To-Channel Workflow

ContextGo is not only for local agent work. It can also publish a working agent into real channels and real audiences, turning it into a service surface.

## Good fit if...

- you want an agent to work inside a group, team, or external entry point
- private local usage is no longer enough
- you want one agent to serve more than one audience

## Starter Kit

- Recommended Workbench: `Conversation Cowork Workbench`
- Recommended Connectors: `Channel Accounts`, `Publication Targets`, `Audience Routing`
- Recommended Runtime: `Stable service runtime`
- Recommended Agent Package: `Service / Ops / Support package`
- Recommended Skills: `reply`, `routing`, `summary`, `channel-aware tools`
