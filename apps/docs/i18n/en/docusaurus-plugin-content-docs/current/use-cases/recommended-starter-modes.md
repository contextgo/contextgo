# Recommended Starter Modes

If you do not want to understand the whole product before starting, choose a starter mode first.

Starter modes help you skip the most confusing part of day one.

## Included modes

- Solo Cowork Mode
- Research Mode
- Builder Mode
- Automation Mode
- Remote Mode
- Publication Mode
