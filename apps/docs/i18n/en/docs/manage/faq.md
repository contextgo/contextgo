# FAQ

## Why can't the phone fully replace the desktop host?

Because ContextGo keeps execution authority on the host. Mobile is a remote work surface, not a full execution replacement.

## Why does a runtime show as installed but still not work?

Because installed only means the program exists. It does not automatically mean signed in or ready.

## Why should I start from one small workflow first?

Because ContextGo is broad. One real successful workflow teaches the system better than enabling everything at once.
