# Updates

What users need to understand is:

- where official installers come from
- where update history lives
- how to confirm the current version

They should not need to start from internal release repository mechanics.

## The simplest rule

- trust the official download path
- trust the official release history
- expect the desktop updater and the download page to reflect the same product line
