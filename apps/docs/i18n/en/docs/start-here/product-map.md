# Product Map

If you think of ContextGo as just one chat page, you miss the actual structure.

The product is better understood through these main surfaces:

- Workbench
- Context
- Agents & Capabilities
- Publish
- Collaboration
- Remote & Devices
- Manage

## How to use this map

If you are new:

1. Start with `Start Here`
2. Move into `Use Cases`
3. Come back to `Context` and `Publish` once you understand your main workflow
