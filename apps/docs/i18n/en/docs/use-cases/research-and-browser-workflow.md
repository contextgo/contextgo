# Research And Browser Workflow

If your work lives in the browser, ContextGo helps turn browser context, saved pages, extracted facts, and summaries into one continuous workflow instead of a tab graveyard.

## Good fit if...

- you do research, scanning, comparison, or competitor analysis
- you live in web pages and browser tabs
- you want research outputs to become long-running context

## Starter Kit

- Recommended Workbench: `Browser Research Workbench`
- Recommended Connectors: `Browser Context`, `Saved Pages`, `Web Sources`
- Recommended Runtime: `Research-friendly runtime`
- Recommended Agent Package: `Research / Analyst package`
- Recommended Skills: `web`, `browser`, `extract`, `compare`, `summarize`
