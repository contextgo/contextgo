# Team And Collaboration Workflow

ContextGo is not only moving toward “more agents replying at once”.

It is moving toward collaboration patterns where complex work can be:

- split
- reviewed
- iterated
- carried forward in shared context

## Status

This direction should be treated as preview, not as a fully mature default mode yet.
