# Browser, Tools, And Runtime Actions

In ContextGo, an agent is not only a text generator.

Its real value comes from actions entering the workflow:

- browser actions
- tool calls
- file operations
- runtime actions

## Why users should understand this

If the product is understood only as chat, its real shape is missed.

A better model is:

- the conversation starts the work
- actions execute the work
- files and outputs carry the result
