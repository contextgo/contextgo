# Runtime Center

ContextGo supports multiple runtimes, but the most important thing for users is not the protocol name.

It is understanding:

- what is installed
- what is signed in
- what is actually ready

## Why this page matters

Many users assume "installed" means "usable".  
It often does not.

Runtime Center should help users answer:

- is the runtime present on this machine?
- is it authenticated or configured?
- can it actually work inside this project right now?
