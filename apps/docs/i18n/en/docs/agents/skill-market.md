# Skill Market

Skill Market should not be treated as a small settings add-on.

Its real product role is:

- capability discovery
- project-level extension
- workflow expansion without rebuilding everything

## Why it matters

ContextGo becomes more useful when users can grow a workflow gradually.

Skill Market helps with that by making it easier to:

- discover capabilities
- install them into the current work context
- evolve a project over time
