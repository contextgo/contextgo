# Context Governance

If context only accumulates automatically, it quickly becomes a black box that users cannot understand or trust.

That is why Context Governance matters.

## What it is trying to solve

- what should be kept long term
- what should stay temporary
- what should become a proposal first
- what is stale and should be reviewed again

## Why this is user value

This is not only an architecture concern. It directly affects whether:

- context stays useful
- the system remembers the right things
- project truth stays inspectable
- users understand why the system behaves the way it does
