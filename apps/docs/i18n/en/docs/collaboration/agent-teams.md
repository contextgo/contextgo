# Agent Teams

:::warning Preview

`Agent Teams` should be described as an upcoming direction, not as a fully mature public promise.

:::

![ContextGo agent group creation flow](/brand/product/agent-group-builder.png)

The current UI already shows an early shape of group-based collaboration, but the public docs should still describe it as a preview direction.

Agent Teams matter because they move collaboration from temporary workflow structure toward a more durable multi-role system.

## What this direction means

- more stable roles
- clearer collaboration boundaries
- stronger long-running shared context
