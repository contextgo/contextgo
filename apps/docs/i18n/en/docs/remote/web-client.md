# Web Client

The web client in ContextGo is not another separate product. It is the most universal remote work surface.

## What this page clarifies

The web client is easy to misread as either:

- a hosted SaaS admin panel
- an online workspace that can run independently from the host

Neither is the intended model.

## The stable role of the web client

The safer definition is:

- it opens host work through the browser
- it reuses the same remote product model
- it is optimized for viewing, continuing, controlling, and uploading
- it does not replace the host as execution authority

## What it is best for

The web client is especially good for:

- checking task state
- opening an online host from a browser
- continuing a conversation or task from another device
- reviewing host-side output and deciding what happens next
- getting temporary access without requiring a full desktop install

## What it should not be treated as

The web client should not be treated as:

- a parallel cloud-hosted product
- a new execution host
- a way to bypass host permissions

If the work depends on local files, local CLI tools, long-running tasks, or machine permissions, it still belongs to the host.

## A reliable usage pattern

The steady pattern is usually:

1. keep the desktop host healthy and online
2. open that host from a browser
3. continue by reviewing, summarizing, deciding, or uploading
4. hand heavy execution back to the host when needed

## How web differs from mobile

Web and mobile are both remote clients, but they lean differently:

- web is better for general access and temporary continuation
- mobile is better for quick on-the-go checks and small follow-up steps
- neither changes the fact that the host remains the execution authority

## Common misunderstandings

- "If I can work in the browser, the desktop is no longer important."
- "If I upload a file in web, the file now lives in the browser."
- "If I can see results in a browser, the runtime must also be in the browser."

Those do not match the current product model.
