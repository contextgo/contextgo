# Conversation Cowork Workbench

This is the most mature workbench shape in ContextGo today.

It is useful for:

- starting tasks
- following execution
- handling confirmations
- inspecting outputs and artifacts
- iterating on the same task

## Why it is not just chat

Even when the surface looks conversational, it is carrying more than messages:

- runtime execution
- file outputs
- browser context
- project context
- automation entry points
