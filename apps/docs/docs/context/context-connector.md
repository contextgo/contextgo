# Context Connector

Context Connector 是 ContextGo 最重要的产品能力之一。

它解决的问题不是“再多接一个插件”，而是：

> 怎么把你原来就在用的工作现实，完整接进 ContextGo。

## 它为什么重要

你的工作通常已经存在于：

- 文件
- 网页
- 浏览器行为
- 项目文档
- 外部系统

如果这些东西进不来，Agent 再强也只能在一个空白对话框里猜。

## 用户应该怎么理解它

用户不需要先理解它的底层协议，只需要理解：

- Context Connector 负责把真实来源带进系统
- 这些来源会进入长期上下文
- Agent 会围绕这些真实来源工作
