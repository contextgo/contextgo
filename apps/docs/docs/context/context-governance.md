# Context Governance

ContextGo 的上下文系统如果只是不断自动积累，很快就会变成一个用户无法检查的黑盒。

所以 Context Governance 很重要。

## 它要解决什么问题

- 哪些内容应该长期保留
- 哪些内容只是暂时有效
- 哪些内容应该先变成 proposal，而不是直接写入
- 哪些上下文已经过时或需要重新确认

## 为什么这件事是用户价值

这不只是架构洁癖。

它会直接影响用户体验：

- 上下文会不会越积越乱
- 系统会不会记错东西
- project truth 会不会被自动写坏
- 用户还能不能理解系统为什么这样工作

## 用户应该怎么理解它

你可以把它理解成：

- 上下文的审核机制
- 记忆的治理机制
- 长期工作系统的质量控制层
