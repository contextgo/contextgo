# Quick Start

第一天只做一件事：让 ContextGo 在一条真实任务上跑通。

## 第一步：准备桌面主机

ContextGo 的真实执行权威仍然是桌面主机。

先确保：

- 桌面端已安装
- 可以正常登录
- 当前设备处于可用状态

## 第二步：准备一个可用 runtime

不要一次接很多 runtime。

先确认至少有一个 runtime 真正是：

- 已安装
- 已登录或已配置
- 已就绪

## 第三步：不要从假任务开始

最好的第一条任务应该来自你今天本来就要做的事，例如：

- 整理一份资料
- 总结一组网页
- 处理一个项目问题
- 写一个草稿

## 第四步：把真实上下文带进来

至少带进来其中两类：

- 文件
- 网页
- 项目文档
- 浏览器上下文

## 第五步：只让它做一件明确的小事

例如：

- 先总结现状
- 先列下一步
- 先起一个提纲
- 先定位一个问题

## 下一步

如果已经跑通一条真实任务，就去 [Use Cases](/use-cases) 选最贴近自己的打开方式。
