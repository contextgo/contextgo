# Choose Your Setup

ContextGo 可以承接很多能力，但不是所有人都应该从同一种配置开始。

最好的起步方式，是先选一个贴近自己真实工作方式的 setup。

## Setup 1: Desktop-Only

适合：

- 主要在一台电脑前工作
- 先想把本地任务跑顺

建议先启用：

- 一个 ready runtime
- 一个最常用 workbench
- 最基本的 context sources

## Setup 2: Desktop + Web

适合：

- 偶尔需要离开桌面，但仍以电脑为主
- 希望在浏览器里继续查看和控制任务

建议先启用：

- 桌面主机
- Web 端入口
- 基础远程访问

## Setup 3: Desktop + Mobile

适合：

- 不想一直守在电脑前
- 需要在手机上继续看状态、控制任务或上传文件

建议先启用：

- 稳定的桌面主机
- 手机端远程接入
- 适合远程管理的工作流

## Setup 4: Builder Setup

适合：

- 独立开发者
- 经常使用 code runtime
- 项目上下文对工作质量影响很大

建议先启用：

- code-capable runtime
- project docs
- browser context
- hooks / commands

## Setup 5: Publication Setup

适合：

- 目标是把 Agent 发到渠道里
- 本地工作只是第一步

建议先启用：

- 一个本地已跑顺的 Agent
- 一个目标渠道
- 一个清晰 audience
