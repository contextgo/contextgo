# What Is ContextGo

ContextGo 不是普通 AI 聊天工具，也不是某一个代码 Agent 的手机遥控器。

它更准确的定义是：

> 一个 desktop-first、local-first、multi-runtime、multi-agent、multi-surface 的 AI Native Workbench。

## 它和普通 AI 工具的区别

普通 AI 工具通常强调：

- 一个对话框
- 一个模型或一个 Agent
- 一次性问答或一次性执行

ContextGo 更强调：

- 工作台
- 长期上下文
- 多种 runtime
- 自动化
- 发布到渠道
- 多端远程

## 它真正解决的问题

你的真实工作并不只发生在一个输入框里，而是分散在：

- 文件
- 网页
- 浏览器
- 文档
- 历史结果
- 外部系统
- 不同设备

ContextGo 的价值，是把这些东西组织起来，让 Agent 真的在一个工作系统里工作。
