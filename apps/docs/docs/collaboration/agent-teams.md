# Agent Teams

:::warning Preview

`Agent Teams` 应该被表达成未来方向，不应该在当前公开文档里被当成完全成熟能力来承诺。

:::

Agent Teams 的意义，不是再多一个抽象名词，而是让协作从“临时 workflow”走向“长期稳定团队结构”。

## 这一方向意味着什么

- 角色更稳定
- 协作关系更明确
- 长期上下文更容易沉淀
