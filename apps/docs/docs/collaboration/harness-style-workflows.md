# Harness-Style Workflows

Harness 风格工作流最重要的点，不是名字，而是角色分离。

它强调：

- 规划角色
- 执行角色
- 评审角色

不要都由一个 Agent 同时承担。

## 为什么这样更适合复杂任务

因为复杂任务的失败常常不是能力不够，而是：

- 目标不清
- 自我评估偏差
- 缺少阶段性交接

Harness 风格就是为了降低这些问题。
