# Multi-Agent Collaboration

多 Agent 协作不等于“同时打开几个机器人”。

更准确的价值在于：

- 分工
- 互相补位
- 降低单 Agent 偏差
- 提升复杂任务的推进质量

## 什么任务适合多 Agent

适合：

- 任务天然分阶段
- 需要不同角色判断
- 需要规划、执行、评审分开

不适合：

- 一步就能完成的小任务
- 目标非常简单的单线程任务
