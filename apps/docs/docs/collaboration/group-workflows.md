# Group Workflows

Group workflow 不是简单的“群聊版对话”。

它更重要的作用，是提供一个协作容器，用来承接：

- parent / child sessions
- shared workspace
- 多角色推进

## 用户应该怎么理解它

可以把它理解成：

- 一个协作任务的容器
- 不是多个独立会话的临时集合
