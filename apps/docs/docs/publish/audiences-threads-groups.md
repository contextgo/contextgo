# Audiences, Threads, Groups

一个渠道里，真正被服务的对象不只是“这个平台”。

更重要的是：

- audience
- group
- topic
- thread

## 为什么这件事重要

因为发布的真实问题不是“接入了哪个平台”，而是：

- 你到底在服务谁
- 一个入口和另一个入口是不是不同 audience
- 群组里的 topic/thread 是否应该绑定不同能力

## 用户应该怎么理解它

简单理解：

- Channel 是渠道
- Account 是入口账号
- Audience / Group / Thread 是被服务的对象层
