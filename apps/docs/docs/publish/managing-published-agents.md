# Managing Published Agents

已发布的 Agent 不应该被理解成“一次配置完成后就结束”的对象。

它更像一个持续运营中的能力入口。

## 为什么这件事重要

因为发布之后你还会持续面对：

- 当前绑定对不对
- audience 路由要不要调整
- 哪些入口只是临时接管
- 哪些入口需要长期运营

## 用户应该怎么管理它

最重要的是明确两件事：

- 这是临时试运行，还是长期发布
- 这个入口服务的是谁、目标是什么
