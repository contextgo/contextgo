# Publish One Agent To Many Places

ContextGo 的一个重要方向，是让同一个已经跑顺的 Agent 不只停留在本地线程里，而是可以进入多个真实入口。

## 这意味着什么

你可以逐步走向：

- 一个 Agent 服务多个 audience
- 一个能力跨多个渠道复用
- 一个团队在多个入口使用同一套能力

## 第一阶段怎么做

第一阶段建议非常保守：

1. 先跑顺一个本地 Agent
2. 先接一个渠道
3. 先服务一个明确 audience
4. 再逐步扩展
