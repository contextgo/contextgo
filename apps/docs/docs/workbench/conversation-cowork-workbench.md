# Conversation Cowork Workbench

这是当前 ContextGo 最成熟的一种工作台形态。

它适合：

- 发起任务
- 查看执行流
- 处理 tool confirmations
- 查看结果和产物
- 持续围绕一个任务迭代

## 它不是普通聊天页

即使你看到的是对话流，这个工作台背后承接的也不仅仅是聊天：

- runtime 执行
- 文件结果
- 浏览器上下文
- 项目上下文
- 自动化入口
