# AI Native Workbench Overview

ContextGo 的产品主模型正在从“一个聊天页承载所有能力”，演进成“一个可以承接多种工作面的 Workbench Host”。

这意味着：

- workbench 才是产品工作面
- conversation 只是 workbench 的一种
- preview、browser、assets、context 都不应该再只是聊天附属物

## 为什么这件事重要

因为未来 ContextGo 面向的不只是：

- 通用聊天
- 代码型 cowork

还包括：

- 浏览器研究
- 内容生产
- 文件工作流
- Space / Context 治理
- Group / Orchestration
