# Settings Guide

设置页对普通用户最重要的，不是“这里有多少配置项”，而是“哪些设置对应哪类能力”。

## 建议的理解方式

按用户任务理解设置，而不是按内部模块名理解：

- 账号与设备
- runtimes
- skills 和 automation
- remote
- publish
