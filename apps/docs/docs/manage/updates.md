# Updates

用户需要理解的是：

- 官方安装包从哪里来
- 更新从哪里看
- 当前版本怎么确认

而不是先理解 release 仓库内部结构。

## 最应该记住的事

- 只认官方下载安装入口
- 只认官方版本历史
- 桌面端和下载页应该指向一致的版本线
