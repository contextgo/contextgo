# FAQ

## 为什么手机不能完全代替桌面主机？

因为 ContextGo 的执行权威仍然是主机。手机端是远程使用面，不是完整宿主。

## 为什么 runtime 显示 installed 但还是不能工作？

因为 installed 只表示程序存在，不等于 signed in，也不等于 ready。

## 为什么我应该先从一个小工作流开始？

因为 ContextGo 的能力面很大，先跑通一个真实小任务，比一开始把所有能力打开更有效。
