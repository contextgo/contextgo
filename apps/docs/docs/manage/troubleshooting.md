# Troubleshooting

排障最好按用户能感受到的症状来开始，而不是先按内部系统组件来想。

常见入口包括：

- 登录没有完成
- 设备没有出现或离线
- runtime 显示 installed 但不能工作
- 手机端无法继续桌面任务
- 发布到渠道后行为不符合预期
