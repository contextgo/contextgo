# Remote Access Overview

ContextGo 的多端模型可以用一句话概括：

> 桌面主机继续负责执行，网页和手机负责接入与控制。

这意味着：

- 桌面主机是执行权威
- Web 和手机不是第二套独立主机
- 手机选的文件最终也会进入主机处理
