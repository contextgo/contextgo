# Mobile Shells

手机端在 ContextGo 里的角色，不是“另一套完整产品”，而是远程使用面。

它们的定位是：

- iPhone、Android、HarmonyOS 都复用相同的远程产品模型
- 桌面主机继续负责执行
- 手机更适合查看、控制、继续任务和上传文件
