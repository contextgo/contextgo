# Linux Host And CLI

Linux 在 ContextGo 里不应该被视为次要平台。

它可以承担两种重要角色：

- Host Runtime 平台
- CLI 运行面

## 为什么它重要

因为很多持续运行、远程访问、自动化场景，本来就更适合放在 Linux 上。
