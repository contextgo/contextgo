# Same Experience Across Devices

ContextGo 的目标不是给桌面、网页、手机分别做三套产品。

它更重要的目标是：

- 一套核心产品逻辑
- 多种接入面
- 尽量一致的使用心智

## 为什么这件事重要

如果三端逻辑完全不同，用户就要重新学习三次。

ContextGo 更适合的方式是：

- 桌面主机负责执行
- 网页和手机共享远程使用心智
