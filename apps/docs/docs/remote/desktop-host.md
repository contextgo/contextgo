# Desktop Host

在 ContextGo 的多端模型里，桌面主机不是某个可有可无的入口，它是执行权威。

它负责：

- 文件
- runtimes
- tools
- 长任务
- 本地环境相关能力

## 为什么用户一定要理解这一点

因为这会直接影响：

- 为什么手机不能完全替代桌面
- 为什么主机在线状态如此重要
- 为什么“远程使用”和“本地执行”是两件事
