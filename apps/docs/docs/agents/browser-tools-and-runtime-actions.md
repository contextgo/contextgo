# Browser, Tools, And Runtime Actions

ContextGo 里的 Agent 不只是“说话”。

它真正的价值，在于这些动作可以进入工作流：

- 浏览器动作
- tool calls
- 文件操作
- runtime actions

## 为什么这一页重要

如果用户只把 Agent 理解成文本回复，就会低估 ContextGo 的产品形态。

ContextGo 更像是：

- 以对话为入口
- 以动作和结果为真正工作内容

## 用户应该怎么理解

最简单的理解方式：

- 对话是入口
- 动作是执行
- 文件和结果是产物
