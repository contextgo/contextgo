# Built-in Assistants

ContextGo 适合普通用户的一点，是它不要求你第一天就自己拼完整个能力栈。

内置 Assistants 的作用，就是先给你一个已经可以工作的起点。

![ContextGo 内置助手列表](/brand/product/agent-library-screen.png)

这些内置助手更像已经整理好的工作模式入口，而不是一堆等你自己拼装的零件。

## 它们适合什么时候用

适合：

- 第一次上手
- 还不清楚该怎么组合 runtime、skills 和自动化
- 想先体验某一类工作方式

不适合：

- 已经非常明确要自己定义一套专用能力包

## 它们和 Runtime 的区别

Runtime 决定的是“谁来执行”。

Built-in Assistant 决定的是“以什么工作方式开始”。

也就是说：

- runtime 是执行后端
- assistant 是工作模式入口

## 该怎么选

最简单的原则：

- 做通用任务：先选通用 Cowork assistant
- 做研究：先选更偏 research 的 assistant
- 做开发：先选 builder / engineering 风格 assistant
