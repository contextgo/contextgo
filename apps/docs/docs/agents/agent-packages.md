# Agent Packages

在 ContextGo 里，Assistant 不只是一个 preset。

它更接近一个 `Agent Package`：

- 可以携带规则
- 可以携带 docs
- 可以携带 skills
- 可以携带 hooks / commands / schedules

这也是为什么 ContextGo 的能力边界，不应该被某个单独 runtime 文件结构绑死。
