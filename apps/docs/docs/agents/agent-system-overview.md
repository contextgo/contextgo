# Agent System Overview

在 ContextGo 里，用户看到的不应该是一堆孤立概念。

更好的理解方式是：

- Agent 是执行角色
- Runtime 是执行后端
- Agent Package 是能力包
- Skills / Hooks / Commands / Schedules 是可装配能力
