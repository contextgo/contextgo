# Use Cases

这一部分不是功能总览，而是按真实工作方式告诉你：ContextGo 应该从哪种模式进入。

## 推荐先读的页面

- [Bring Your Workflow Into ContextGo](/use-cases/bring-your-workflow-into-contextgo)
- [Content And Writing Studio](/use-cases/content-and-writing-studio)
- [Research And Browser Workflow](/use-cases/research-and-browser-workflow)

## 如果你不知道该选哪个

默认顺序：

1. 先读 `Bring Your Workflow Into ContextGo`
2. 再看最贴近你的主要工作类型
3. 用顺以后再回来看 `Recommended Starter Modes`
